
# Return Policy

Policy Type: Return Policy
Policy Version: 1.0
Policy Status: Demo Policy

## 1. Return Eligibility

- Customers can request a return within 7 calendar days of receiving their order.
- Products must be unused and in their original packaging.
- Customers must provide a valid order ID.
- The order must have a delivered status.

## 2. Damaged or Incorrect Products

- Customers can request a return if they receive a damaged, defective, or incorrect product.
- Customers should provide photographs or other evidence of the issue.
- Such requests must be submitted within 7 calendar days of delivery.

## 3. Non-Returnable Products

The following products are not eligible for standard change-of-mind returns:

- Personalized products.
- Perishable goods.
- Products marked as non-returnable.
- Used products that cannot be resold for hygiene or safety reasons.

Applicable consumer rights and legal exceptions must still be respected.

## 4. Return Request Process

1. Customer provides their order ID.
2. The system retrieves order information.
3. The system checks the delivery date and order status.
4. The system checks the return eligibility conditions.
5. Eligible requests are submitted for human approval.
6. After approval, the support team provides return instructions.

## 5. Important Restrictions

- The AI assistant must never claim that a return has been approved without confirmation.
- The AI assistant must never claim that a product has been collected without confirmation.
- If the delivery date is unavailable, the assistant must ask for human assistance.
- If eligibility is unclear, escalate the request to a human support agent.
